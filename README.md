# java-student-management-system

Project Description

A simple Java-based Student Management System developed to manage student records.

Features

* Add student records.
* Store student names and marks.
* View registered students.
* Calculate pass and fail results.
* Simple menu-driven interface.

Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

Purpose

This project was developed to practise Java programming, object-oriented programming and problem-solving skills.
